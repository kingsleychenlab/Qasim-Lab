So to bring it together.

The project tested whether later-remembered words showed higher EEG-to-AI
embedding fidelity than forgotten words. The final session-aware logistic
mixed-effects model did not support this prediction: embedding fidelity was not
significantly associated with later recall.

The reason is informative, not disappointing. Raw cosine looked high, but that
was inflated by a shared embedding direction; when we measured word-specific
decoding properly, it was at chance. So there wasn't a reliable brain-to-embedding
signal for a memory effect to build on — which is exactly what you'd expect from
raw broadband EEG, a simple linear model, and a small sample.

What we do have is a complete, rigorously audited, fully reproducible pipeline,
and an honest negative result that's robust to how we set up the regression.

The path forward is clear: strengthen the decoding side first — the reference
paper's preprocessing and longer window, a retrieval-based metric, richer
features, and more data — and only then re-ask the memory question. Happy to take
questions.

AI WORD-EMBEDDING FIDELITY AND MEMORY
Summary of the 4-, 16-, and 32-subject runs
================================================================================

The question (same for all three runs)
--------------------------------------------------------------------------------
When someone studies a word, is it more likely to be remembered if their EEG
during encoding does a better job of predicting that word's AI (T5-large)
embedding? That prediction accuracy is what I call "embedding fidelity." The
thing being tested is whether remembered words have higher fidelity than
forgotten ones.

The pipeline (identical in all three runs)
--------------------------------------------------------------------------------
PEERS / OpenNeuro ds004395, ltpFR2 task. For each studied word:
  - Target: T5-large encoder, middle layer (hidden_states[12]), subword tokens
    averaged, EOS/pad left out, so one 1024-dim vector per word.
  - EEG: 300-800 ms after word onset, 129 channels x 250 timepoints = 32,250
    features, raw 500 Hz.
  - Decoding: ridge regression (alpha = 10,000) per subject/session, 5-fold
    held-out cross-validation, StandardScaler fit on the training folds only.
  - Fidelity: cosine(predicted embedding, true embedding).
  - Memory model: recalled ~ embedding_fidelity + session + (1|subject) + (1|word)
    (logistic mixed-effects, fidelity z-scored so the odds ratio is per 1 SD).
The only thing that changed between runs was the number of subjects.


Run 1 - 4 subjects
--------------------------------------------------------------------------------
Data:
  - 4 subjects, 8 sessions (2 per subject), 4,608 trials
  - 2,423 recalled / 2,185 forgotten (recall rate 0.526)
  - Subjects: LTP269, LTP293, LTP299, LTP303

Main memory model (embedding_fidelity = raw cosine):
  - odds ratio        : 0.971
  - 95% interval      : [0.913, 1.033]
  - p-value           : 0.354
  - coefficient/SD    : -0.0291
  - remembered mean   : 0.84627
  - forgotten mean    : 0.84711
  - difference        : -0.00084

Word-specific decoding sanity checks:
  - Retrieval percentile is around 0.50 (chance), and real performance is about
    equal to the shuffled-label control. The high raw cosine (~0.847) comes from
    a common embedding direction, not from real word decoding.

Takeaway: null. Remembered and forgotten words showed no meaningful difference
in fidelity, and word-specific decoding was at chance. Honest, but a small
sample.


Run 2 - 16 subjects
--------------------------------------------------------------------------------
Data:
  - 16 subjects, 32 sessions (2 per subject), 18,432 trials
  - 9,980 recalled / 8,452 forgotten (recall rate 0.541)
  - The 4 original subjects plus 12 more.

Main memory model:
  - odds ratio        : 0.979
  - 95% interval      : [0.947, 1.013]
  - p-value           : 0.220
  - coefficient/SD    : -0.0211
  - remembered mean   : 0.84337
  - forgotten mean    : 0.84367
  - difference        : -0.00030

Word-specific decoding sanity checks (averaged over 32 sessions):
  - true-word percentile : real 0.4977  vs  shuffled 0.5011  (chance 0.5)
  - top-5 retrieval      : real 0.0071  vs  shuffled 0.0088
  - top-10 retrieval     : real 0.0162  vs  shuffled 0.0184

Takeaway: still null. Four times the data tightened the interval, but the odds
ratio stayed around 0.98 (interval still includes 1.0). Word-specific decoding
was still at chance, real about equal to shuffled. More subjects didn't make an
effect appear.


Run 3 - 32 subjects
--------------------------------------------------------------------------------
Data:
  - 32 subjects, 64 sessions (2 per subject), 36,864 trials
  - 17,040 recalled / 19,824 forgotten (recall rate 0.462)
  - The 16 previous subjects plus 16 more.

Main memory model:
  - odds ratio        : 0.986
  - 95% interval      : [0.963, 1.009]
  - p-value           : 0.218
  - coefficient/SD    : -0.0145
  - remembered mean   : 0.84501
  - forgotten mean    : 0.84553
  - difference        : -0.00052

Word-specific decoding sanity checks (averaged over 64 sessions):
  - true-word percentile : real 0.4975  vs  shuffled 0.5011  (chance 0.5)
  - top-5 retrieval      : real 0.0074  vs  shuffled 0.0088
  - top-10 retrieval     : real 0.0164  vs  shuffled 0.0180
  - mean true-word rank  : 290.0  (chance 288.5)

Takeaway: still null, and the estimate is now settling right on "no effect."
Word-specific decoding stays at chance across all 32 people.


How the runs compare
================================================================================

Side by side (main model, raw cosine, odds ratio per 1 SD of fidelity):

  quantity            4-subject      16-subject     32-subject
  subjects                    4              16             32
  sessions                    8              32             64
  trials                   4608           18432          36864
  odds ratio             0.971           0.979          0.986
  95% interval    [0.913,1.033]   [0.947,1.013]  [0.963,1.009]
  p-value                0.354           0.220          0.218
  rem - forg diff     -0.00084        -0.00030       -0.00052
  conclusion          no effect       no effect      no effect

What changes as subjects go up:
  1. The odds ratio drifts toward 1.0 (0.971 -> 0.979 -> 0.986). Since 1.0 means
     "no effect," the estimate is converging on exactly no association.
  2. The interval gets narrower and stays centered on 1.0 ([0.913,1.033] ->
     [0.947,1.013] -> [0.963,1.009]). More data means more precision, and that
     precision lands on "no effect" instead of turning one up.
  3. The p-value stays well above 0.05 (0.354, 0.220, 0.218). Never significant.
  4. The remembered-minus-forgotten difference stays tiny and slightly negative
     at every scale. If anything, higher fidelity goes with slightly less recall,
     the opposite of the prediction, and not significant.

What doesn't change:
  - Word-specific decoding is at chance in all three runs (percentile ~0.50,
    real about equal to the shuffled-label control). The model never identifies
    the correct word above chance.
  - The high raw cosine (~0.845) is an artifact of the shared embedding direction
    in all three runs, not evidence of decoding.

What it means:
  - The null holds up. It ran from 4 to 16 to 32 subjects, across 36,864 trials.
    Scaling didn't reveal a hidden effect, it just sharpened the estimate onto
    "no effect."
  - The bottleneck is the decoding method, not the sample size. Raw broadband
    300-800 ms EEG with a linear ridge can't decode word identity above chance,
    so there's no reliable fidelity signal for a memory effect to build on.
    Adding people can't fix a signal that isn't there.
  - Any next step has to strengthen the decoding stage first (the reference
    paper's EEG preprocessing and longer ~3 s window, a retrieval / top-k
    accuracy metric, richer features like time-frequency band power or spatial
    filtering, or a neural decoder), and only then re-test the memory question.


Final conclusion
================================================================================
The project tested whether words that were later remembered showed higher
EEG-to-AI embedding fidelity than words that were forgotten. Across 4, 16, and
32 subjects, the session-aware logistic mixed-effects model didn't support that:
fidelity was not significantly tied to later recall. The result is a complete,
audited, honest null that only gets more solid as the sample grows.
================================================================================
